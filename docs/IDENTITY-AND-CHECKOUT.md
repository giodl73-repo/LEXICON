# Lexicon Identity And Checkout Boundary

Status: active; reconciled with public main on 2026-11-01.

| Surface | Active value | Rule |
|---|---|---|
| Public repository | LEXICON | GitHub, portfolio and cross-repo references. |
| Product and method | Lexicon | New books, schemas, commands and publication surfaces. |
| Local checkout | repos/knowledge-systems/factorium | Historical path; do not infer identity from the folder. |
| Historical imports | Formarium and Factorium | Frozen contracts and source evidence remain readable. |

New work uses `.lexicon`, `.lexicon-query`, and `lexicon-*` names. Do not create
new active `.factorium`, `.factorium-query`, `factorium-*`, `.formarium`,
`.formarium-query`, or `formarium-*` contracts. Do not rename, move, or rewrite
historical Factorium paths solely to make the checkout name match the public
repository. The same custody rule applies to frozen Formarium imports.

Before onboarding, simulation, preview or portfolio handoff, state public
LEXICON, active Lexicon, local repos/knowledge-systems/factorium and frozen
Formarium/Factorium imports together. Stable FRM-PF-06 retains its original
intent while following the current published product identity. The historical
Formarium doctrine result remains unchanged as a dated record.
