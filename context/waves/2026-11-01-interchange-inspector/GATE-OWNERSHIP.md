This classification does not make the repository's full native audit green.
It defines the release inputs and required-success checks for the auxiliary
inspector preview without approving a new book or changing failed tests.

## Separate deliverables

The preview accepts supplied strings through the existing reference, relations
and composition-query parsers. It calls no workspace/Markdown/assurance API,
follows no supplied path and performs no HRR/binding/bakeoff experiment. Its
runtime contains only two authored examples. Current reference content is used
as a parser test input and is included, labelled, in the portable source ZIP;
it is not rendered or admitted as a new public book edition.

The public books remain the exact 528-file sim-67 tree from `0526d86`. Hosted
run `41349782846`, inspector job `124977262003`, rendered that clean source with
Pandoc 3.9 and matched every captured live file. Its raw original manifest,
dictionary, book and proof stay unchanged. Discovery for the new helper belongs
in the repository README, with the books first; no book navigation/manifest
overlay is needed or authorized by this release.
