# Lexicon Doctrine Index

Lexicon uses PITFALL as a compact index over durable reference-doctrine
rules. The indexed entries cite existing product plans, specs, role reviews,
research packets, and validation commands without moving canonical reference
artifacts or historical Factorium imports.

| Namespace | Type | File | Owner |
|---|---|---|---|
| `lexicon-reference` | `principles` | [Lexicon Principles](lexicon-principles.md) | Lexicon maintainers |
| `lexicon-reference` | `invariants` | [Lexicon Invariants](lexicon-invariants.md) | Lexicon maintainers |
| `lexicon-reference` | `pitfalls` | [Lexicon Pitfalls](lexicon-pitfalls.md) | Lexicon maintainers |

Stable FRM doctrine IDs retain their historical identity. Active instructions use
Lexicon; Formarium and Factorium contracts remain frozen historical imports.
