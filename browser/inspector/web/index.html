Interchange inspector draft

Inspect your reference, relations and declared query using Lexicon’s Rust parsers, running locally in WebAssembly.

This checks supplied structure and declared query source hashes. It does not read source paths, check Markdown or review assurance, establish semantic truth, or approve a book release. The books and canonical Tables remain authoritative.

Files stay in this browser. Each document is limited to 512 KiB of UTF-8; the request envelope is limited to 2 MiB. The portable adapter caps query budgets and node depths at 4,294,967,295 on every host. Native canonical transport requires LF, no BOM, canonical ordering and a final LF.

Examples are authored software fixtures, not new canonical Tables or reader evidence.
