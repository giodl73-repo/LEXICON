# Rust 1.95.0 library notices

The copyright document and `licenses/` files are unmodified notices from the
pinned Rust 1.95.0 distribution's `share/doc/rust/` directory. They include
common library and other-platform notices. `provenance.json` records their
original byte hashes and the Rust source revision.

These third-party documents retain their own licenses; Lexicon's first-party
software/content split does not relicense them. They are attribution material,
not extra application implementations. Scoped Git attributes preserve upstream
bytes and exclude only these verbatim documents from whitespace-error checks.
