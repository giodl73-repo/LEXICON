# Learning, Memory, Attention, Reasoning, and Skill

Status: candidate anchor entry

## Orientation

Learning is a change in knowledge, understanding, capacity, disposition, or
performance attributable to experience, practice, study, or instruction.
Memory concerns retention and later availability; attention concerns selective
allocation of processing; reasoning connects represented premises or states to
a conclusion; skill is a developed capacity for performance under conditions.

## Sense table

| Sense | Governing question | Role |
|---|---|---|
| `learning` | What changed for which learner through which experience or activity, with what evidence? | change in learner state or capacity |
| `memory` | What content or capacity is retained, stored, reconstructed, or made available over which interval? | retention and retrieval capacity |
| `attention` | Which information, task, or stimulus receives selective processing under what demands? | selective allocation process |
| `reasoning` | Which premises, representations, rules, or transformations support which conclusion? | inferential cognitive activity |
| `skill` | Which developed capacity enables which performance under what conditions and criteria? | performance capacity |

## Root factorization

```text
cognitive-capacity-use
  := learner, agent, population, or system
   x content, task, stimulus, premises, and target performance
   x prior state, experience, practice, study, and instruction
   x attention allocation, demands, distraction, and context
   x encoding, retention interval, retrieval cue, and reconstruction
   x representation, inference rule, strategy, and conclusion
   x capacity, performance, transfer, retention, and adaptation
   x method, evidence, uncertainty, and alternative explanation
```

## Decisive distinctions

| Pair | Shared feature | Decisive distinction |
|---|---|---|
| Learning vs. performance | performance may evidence learning | durable or attributable change vs. observed act under current conditions |
| Memory vs. record | either retains content | cognitive availability or reconstruction vs. external inscription |
| Attention vs. intention | either can guide action | selective processing allocation vs. commitment to act |
| Reasoning vs. inference record | either connects premises and conclusion | activity by an agent vs. reconstructable logical/evidential relation |
| Skill vs. knowledge | either supports success | capacity for performance vs. epistemic standing toward content |

## Dependencies and stopping boundary

Perception, motive, intention, evidence, human error, performance evaluation,
and process execution retain their owners. This Table does not diagnose a
learner, prescribe instruction, equate neural activity with a psychological
construct, or enumerate memory systems and cognitive architectures.

## Selection procedure

1. Name learner or agent, task/content, context, and time.
2. Identify change, retention, selection, inference activity, or capacity.
3. Separate latent capacity from observed performance.
4. Record prior state, intervention or experience, measure, and alternatives.
5. Test retention and transfer only when evidence supports those claims.
6. Preserve uncertainty, individual variation, and contextual limits.

## Reference Delta

| Reference form | Typical contribution | Lexicon delta |
|---|---|---|
| Cognitive science | supplies mechanisms and experimental constructs | requires construct, task, and evidence alignment |
| Learning science | connects learners, contexts, culture, and instruction | keeps learning separate from educational provision |
| Competency framework | lists observable capabilities | separates skill capacity from one performance score |

## Failure signs

- one successful performance is treated as durable learning;
- external storage is called memory without a declared system account;
- attention, motivation, and intention share one field;
- reasoning is inferred from a correct answer alone;
- a test score is treated as the skill itself;
- cognitive or educational advice is generated from the Table.
