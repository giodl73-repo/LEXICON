# Lexicon Roadmap Wave 5 Tasks

Status: author-only structural rehearsal; not reader evidence

## Task W5A — Which sound or writing level is intended?

Separate phone, phoneme, grapheme, code point/glyph, orthography, and pronunciation.

## Task W5B — Which linguistic unit is intended?

Separate lexeme, word/form/token, phrase, clause, sentence, and utterance.

## Task W5C — Which grammar evidence is intended?

Separate syntax, broader grammar, acceptability, grammaticality, frequency, and usage.

## Task W5D — Which expression transformation is intended?

Separate translation, paraphrase, declared equivalence, adaptation, and transcreation.

## Task W5E — Which cultural relation is intended?

Separate culture, subculture, community-recognized heritage, tradition, and cultural practice.

## Task W5F — Which significant action is intended?

Separate ritual, ceremony, observance, sacred practice, symbolic action, and routine.

## Task W5G — Which artwork description is intended?

Separate artwork status, medium, form, composition, artistic style, and genre.

## Task W5H — Which aesthetic question is intended?

Separate property, experience, judgment, taste, liking, and value.

## Task W5I — Which production or reception role is intended?

Separate creation, authorship, contribution, performance, interpretation, and reception.

## Rehearsal boundary

Pass establishes routing only and supplies no universal, community, sacred,
authenticity, aesthetic-authority, attribution, rights, or legal determination.
